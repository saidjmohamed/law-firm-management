# مكتب الاستاذ سايج محمد - محام لدى المجلس

> نظام إدارة مكتب محاماة جزائري متكامل - يعمل بدون إنترنت (PWA)

## المميزات

- 📴 **يعمل أوفلاين** - تطبيق ويب تقدمي (PWA) يعمل بدون اتصال بالإنترنت
- ⚖️ **إدارة القضايا** - تسجيل وتتبع كل القضايا مع تفاصيل كاملة
- 👥 **إدارة الموكلين** - قاعدة بيانات شاملة للموكلين
- 📅 **الجلسات والتقويم** - تتبع الجلسات القادمة والتأجيلات
- 💰 **المدفوعات** - تتبع الأتعاب والمدفوعات والمتبقي
- 🏛️ **الهيئات القضائية** - التسلسل الهرمي للقضاء الجزائري (المحكمة العليا، المجالس القضائية، المحاكم، القضاء الإداري)
- 📄 **إنشاء ملف القضية** - توليد صفحة HTML بتفاصيل القضية للطباعة أو الحفظ كـ PDF
- 💾 **النسخ الاحتياطي** - تصدير واستيراد البيانات بتنسيق JSON
- 🌙 **الوضع الداكن** - دعم السمة الفاتحة والداكنة
- 📱 **متوافق مع الهاتف** - تصميم متجاوب يعمل بشكل مثالي على الهواتف
- 🔤 **واجهة عربية** - دعم كامل للغة العربية (RTL)

## التقنيات المستخدمة

- **Next.js 16** - إطار عمل React
- **Dexie.js** - قاعدة بيانات IndexedDB للعمل أوفلاين
- **Zustand** - إدارة الحالة
- **shadcn/ui** - مكونات واجهة المستخدم
- **Tailwind CSS 4** - التنسيق
- **TypeScript** - لغة البرمجة

## التثبيت والتشغيل

```bash
# تثبيت الحزم
npm install

# التشغيل في وضع التطوير
npm run dev

# البناء للإنتاج
npm run build
```

## هيكل المشروع

```
src/
├── app/              # Next.js App Router
├── components/       # مكونات التطبيق
│   ├── app-shell.tsx     # الهيكل الرئيسي (شريط جانبي + محتوى)
│   ├── dashboard.tsx     # لوحة التحكم
│   ├── clients.tsx       # إدارة الموكلين
│   ├── cases.tsx         # إدارة القضايا
│   ├── sessions.tsx      # إدارة الجلسات
│   ├── calendar.tsx      # التقويم
│   ├── courts.tsx        # الهيئات القضائية
│   ├── payments.tsx      # المدفوعات
│   ├── delays.tsx        # التأجيلات
│   ├── case-print.tsx    # إنشاء ملف القضية HTML
│   ├── archives.tsx      # الأرشيف
│   ├── backup.tsx        # النسخ الاحتياطي
│   ├── settings.tsx      # الإعدادات
│   └── ui/               # مكونات shadcn/ui
├── hooks/            # React Hooks
└── lib/              # المكتبات والثوابت
    ├── db.ts             # قاعدة البيانات (Dexie.js)
    ├── store.ts          # إدارة الحالة (Zustand)
    ├── constants.ts      # الثوابت (الولايات، أنواع القضايا...)
    ├── backup.ts         # خدمة النسخ الاحتياطي
    └── utils.ts          # أدوات مساعدة
```

## التسلسل الهرمي للقضاء الجزائري

1. **المحكمة العليا** - 7 غرف، بدون مجلس
2. **المجالس القضائية** - 10 غرف
3. **المحاكم** - تابعة لمجلس قضائي، 10 أقسام
4. **القضاء الإداري** - استئنافي، ابتدائي، تجاري متخصص
